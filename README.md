# Aru-Phantom（アルファントム）

Android端末でアプリを複製し、別々のデータで使うためのアプリです。APK-Toolboxをもとに、日本語の説明・ボタン・設定項目を追加した独立版です。

- **ダウンロード**：[Releases](https://github.com/45kikurage-rgb/aru-phantom/releases/latest)
- **開発元**：[bl3xand/APK-Toolbox](https://github.com/bl3xand/APK-Toolbox)
- **ライセンス**：[GPL-3.0](LICENSE)。元の著作権・依存プロジェクトの表記を維持します。
- 元プロジェクトの詳細とクレジット：[開発元README](docs/README.upstream.md)

## インストール

Android 8.0以降に対応します。Releasesの `Aru-Phantom-…-arm64-v8a.apk` は主に最近のAndroidスマートフォン用です。CPUが不明な場合は `universal.apk` を選んでください。

APKを開いてインストールし、初期画面からファイルへのアクセスとアプリのインストールを許可してください。日本語の端末では日本語表示になります。アプリ内「設定 → 表示言語 → 日本語」からも切り替えられます。

アプリIDは `com.aruno.aruphantom` です。開発元版とは別アプリとしてインストールできます。開発元版のデータやログイン状態は自動移行しません。

## 使い方

1. **アプリの複製**を開き、インストール済みのアプリかAPKファイルを選びます。
2. パッケージ名とアプリ名を確認します。複製ごとに異なるパッケージ名が必要です。
3. 必要に応じてアイコンの目印と、複製アプリに与える権限を設定します。
4. **複製を作成**を押し、**インストール**または**保存**を選びます。
5. 作成したアプリは**複製済み**から確認・更新できます。

複製はデータが空の別アプリとして作成されます。元アプリのデータ・ログイン状態は引き継ぎません。Googleログイン・決済・署名チェックなどに依存するアプリでは動作しない場合があります。LINEを含む個別アプリの動作は実機未検証です。

## この版の変更

2026-10-22：Aru-Phantomへの改名、日本語リソース・配布元画面の日本語辞書、独立アプリID、更新確認先の自分のリポジトリへの変更を実施しました。

開発元の説明に加え、配布元画面ではObtainiumの日本語訳を利用しています（[ImranR98/Obtainium](https://github.com/ImranR98/Obtainium)、GPL-3.0）。独自の追加説明は本リポジトリで翻訳しています。

この配布にはTelegram APIの認証情報を含めません。Telegramチャンネル連携は利用できません。操作ログの内部診断文や外部サイトの更新内容・エラー本文は英語などで表示される場合があります。

## ビルド

JDK 17、Android SDK 36、リポジトリ指定のGradleを用意して `./gradlew assembleRelease` を実行します。署名用の `keystore.properties` とTelegram用の `telegram.properties` はリポジトリに保存しません。署名情報がなければ未署名APKになります。GitHub Actionsは利用しません。

元プロジェクトの `dev`・`sources-tab` ブランチとタグは履歴として維持し、日本語版は `main` で管理します。
